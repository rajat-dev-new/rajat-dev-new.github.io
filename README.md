## 🏛️ Architectural Highlights of the Portfolio

1. **Interactive Architecture Blueprint Explorer (`#architecture`):**
   - Clickable interactive system design flow diagrams for three enterprise patterns:
     - **LangGraph Agentic SDLC & BRD Extraction Mesh**
     - **AWS Enterprise Cloud Topology (DENSO Production Readiness)**
     - **Deterministic Hybrid RAG Engine (Retail Loan Credit Analyst)**
   - Includes dynamic node inspector showing implementation rationale, trade-offs, and technical specs.

2. **The Developer Journey (`#journey`):**
   - Chronological engineering progression from early full-stack systems at MateBench (2020-2023), to high-throughput backend data engineering at Maaze Underwriting (2023-2025), to enterprise AI and cloud platform architecture at NTT DATA (2025-Present).

3. **Featured Production Case Studies (`#projects`):**
   - **Tesseract Forge / NDIL:** LangGraph state machine, tool calling, FAISS + Graph DB, Okta OIDC + PKCE.
   - **DENSO / Hyper Intelligence:** AWS VPC, RDS PostgreSQL, Redis, EFS, SSM, IAM, Trivy container security scans.
   - **Munich Re:** High-performance Python 3.12 / FastAPI microservice replacing legacy Java actuarial workflows.
   - **Credit Analyst Engine:** Deterministic financial rules paired with local LLMs (Ollama) and FAISS.
   - **TalkTrack:** Multimodal AI quality, OCR, camera capture, and deployment validation.

4. **Interactive CLI Terminal (`#terminal`):**
   - Functional command line interface supporting `help`, `bio`, `skills`, `langgraph`, `projects`, `architecture`, `contact`, and `clear`.

5. **Direct Collaboration & Inquiries (`#contact`):**
   - Direct engineering communication channels, CV download options, and 1-click email invitation links.

## 🚀 Local Development & Preview

This portfolio is built with pure, unbloated modern web technologies:
- HTML5 (Semantic, accessible markup)
- Modern CSS (Custom properties, dark mode, glassmorphism, responsive grids)
- Vanilla JavaScript (High-performance event-driven architecture visualizer and CLI)
